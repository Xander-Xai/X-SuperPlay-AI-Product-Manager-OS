# 01 产品管理基础

**目标**：理解 PM、PO、项目经理、技术负责人、产品工程师的职责边界；把“做功能”转为“改善用户任务”。

### 理论骨架
1. 产品生命周期：Discover → Define → Deliver → Measure → Decide。
2. 产品四风险：用户价值、可用性、技术可行性、商业可持续性。
3. Output vs Outcome：发布聊天页只是产出；用户可信地完成任务才是结果。
4. B2B/B2C 与内部/外部产品的差异：买方、终端使用者与审批者未必同一人。
5. 产品决策与工程实现协作：PM 负责价值和范围，工程负责人承担架构、安全与可运行性。

### 最小练习
选择一个公开或合成的“企业知识助手”，绘制用户→任务→现有替代→问题→产品成果→指标。写三条明确“不做”。

### 闭卷测试
客户强烈要求多 Agent，但现有 Excel/人工流程可以完成任务，怎样调查并可能拒绝？说出真实可观察证据、失败条件和下一步。详见 [用户研究](../02-User-Research/README.md)。
