# 02 用户研究、JTBD 与需求发现

目标：避免把“用户说想要 AI”误判成“用户愿意切换/付费”。

### 必会
- 观察、半结构化访谈、任务走查、可用性测试；比较言语与真实行为。
- JTBD：用户在什么场景、为取得什么进展、目前怎样完成任务。
- 用户角色、决策者、买方、使用频率、替代方案和切换成本。
- 证据等级：授权真实行为/付费 > 最近事件细节 > 受访者意见 > 公开讨论 > AI 模拟；无法外推小样本结论。
- 偏差：诱导性问题、熟人样本、幸存者偏差、确认偏误。

### 最小实践
针对一个场景用 [Interview](../templates/Interview.md) 收集近期真实事件（必须授权），如无访谈对象，用明确标注 SYNTHETIC 的案例。为每条观察填 FACT / INFERENCE / HYPOTHESIS，找反例、研究缺口、下一个可逆试验。公开仓只留去标识摘要与流程。

### 验收
解释“用户是谁、买方是谁、何时痛、为什么当前替代不好、损失是什么、什么证据会推翻想法、最小下一步是什么”。下一步 [战略](../03-Product-Strategy/README.md)。
