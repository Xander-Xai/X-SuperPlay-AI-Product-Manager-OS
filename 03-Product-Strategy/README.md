# 03 产品战略、优先级与商业机会判断

### 知识地图
1. 市场细分：角色、任务频率、紧迫度、触达/采购门槛；TAM 大不等于自己能获得客户。
2. 竞品范围：直接竞品、替代工具、人工外包、规则/搜索，以及什么都不做。
3. 价值主张：谁，在什么任务，比现状改善何种可测结果。
4. 优先级与路线图：RICE/ICE 属讨论工具，评分中的 Reach/Confidence 必须标来源和假设；路标以用户问题/结果组织。
5. 可逆实验、停止条件与机会成本；高维护成本/权限风险可能使“能做”不等于“该做”。

### 练习
对同一问题比较人工服务、规则/关键词搜索、RAG、Agent。分别列出任务成功率、成本、数据权限、失败恢复、部署维护、用户切换成本的预期和依据。用 [ADR](../templates/ADR.md) 定一个最轻试验与反证。

### 独立题
当付费用户数比预期少 70%、或客户不允许上传数据时，如何重排路线图？不能只凭热门技术回答。
