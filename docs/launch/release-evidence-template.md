# Release Gate 证据模板（复制到具体工程仓填写）

> 本仓模板设计完成不等于真实发布通过。真实生产版本必须由工程仓保存运行记录，负责人核实证据。

## 基本信息
- Project / 环境 / 版本 SHA / 数据版本：
- 业务用途 / 用户范围 / 数据授权与许可证：
- 产品 Owner / 工程 Owner / 安全 Reviewer / 发布批准人：
- 本次主要变更 / 非目标 / 停止条件：

## G0–G7 勾核（每项填真实证据链接/失败原因）
- [ ] G0 需求、替代基线、合法用途、用户授权与成功指标
- [ ] G1 架构 ADR、API/DB 契约、故障域与迁移计划
- [ ] G2 服务器授权、租户隔离、角色撤销、敏感信息最小化
- [ ] G3 AI 金标/Eval、拒答、Prompt Injection、工具审批与限额
- [ ] G4 正例/负例、异步幂等、测试/失败注入与记录
- [ ] G5 部署在干净环境可复现、HTTPS/重启、备份/恢复、回滚
- [ ] G6 Trace/SLI、P95/错误率/成本、告警、人工支持责任
- [ ] G7 真实或合成 UAT 的明确区分，商业/数据验收口径

## 验收数据
- 实际命令及退出码/日志 URL：
- 失败案例 1/2/3、复现步骤、修复前后差异：
- 实际负载、延迟、成本的指标/分母/采样窗口：
- 回滚/恢复演练或为何不适用：
- 存在的未解决风险和明确 STOP 规则：
- 人工 GO / HOLD / STOP、批准日期、签署人：

- User: NOT_RUN
- Commercial: NOT_VERIFIED
