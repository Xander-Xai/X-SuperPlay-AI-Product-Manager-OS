# Task-to-Learning Contract（需求驱动学习记录模板）

> 保存的是学习状态，不是客户真实业务或合同；公开仓仅可记录公开/合成内容。

- TASK_ID / 日期 / 来源与授权： 
- REAL_WITH_CONSENT / PUBLIC_RESEARCH / SYNTHETIC / UNKNOWN：
- 具体用户任务 / 失败行为 / 严重程度 / 截止期限：
- 真实证据链接或合成标签：
- 验证不用 AI / 规则 / 已有平台是否足够：
- 阻塞分类 H/E/S/C（只有 S 自动进入教学）：
- 主知识节点 ID（如 ENG06）及直接依赖：
- 已会的前置（人独立前测可证明）：
- 真正不会的知识与权威资料 URL：
- 本次唯一练习的代码/数据/规则：
- 正常用例，失败用例 1、失败用例 2（必须与本次风险相关）：
- 指标、分母、阈值、版本/环境：
- AI 辅助范围 / 何时关闭 AI：
- 人独立演示/排错的真实证据（无则 UNASSESSED）：
- 原工程 repo@SHA / 执行命令 / 输出日志：
- 1/3/7 天迁移新约束与人工评审：
- Engineering / Human / User / Commercial 四轨状态：
- STOP / CONTINUE / CHANGE：
- 该知识怎样迁移到另一个场景（不是必须立刻开发下游产品）：
