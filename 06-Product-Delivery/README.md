# 06 产品交付：研发协作、发布、质量与运营

1. PM 负责用户价值/目标/范围，工程负责人负责架构/安全/可维护性；协作通过 PRD、ADR、验收标准对齐。
2. 拆最小端到端功能：用户行为 → 前端 → API → 数据 → AI/规则 → 用户反馈。定义依赖/非目标/责任人。
3. UAT 同时包括正常流、失败/空态、越权、模型错误、超时、重复写入。
4. 上线准备：版本与变更、CI/测试、监控/成本告警、数据备份、故障降级、回滚、用户支持。
5. 收集真实授权反馈时要区分“技术 Bug”“体验可用性”“用户实际上不需要”。

**练习**：写一份发布 Gate：PRD+Eval+权限+回滚+人工接管+Owner+监控的可观察证据。模拟模型不可用、数据库断开和成本翻倍下的沟通与恢复。未执行不能标“生产通过”。
