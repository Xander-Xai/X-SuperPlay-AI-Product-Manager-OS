# 07 产品数据与增长

## 关键模型
- AARRR：获客、激活、留存、收入、推荐；必须根据真实产品定义分母、时间窗与合格用户。
- 北极星指标反映核心价值：例“每周有证据支持、按用户标准成功完成的查询任务数”，不能只看 DAU/Token/消息量。
- Guardrails：幻觉/越权率、P95、单成功任务成本、人工接管率、用户信任投诉。
- 漏斗、Cohort 留存、归因局限、实验分流、预设主指标和停止规则；没有有效对照不能声称因果。

## 最小埋点字典
| 事件 | 属性 | 说明 |
|---|---|---|
| task_started | 匿名任务类型、版本 | 发起数分母 |
| task_completed | 完成判定、耗时、证据 | 有效任务 |
| answer_flagged | 失败类别、版本 | 质量反馈 |
| human_handoff | 原因、处理结果 | 失败恢复 |

未经授权不存用户敏感提示词全文。**练习**：使用明确合成的 50 条事件，按任务/用户去重并复算转化、留存和成本；写出五条可能造成误判的测量偏差。官方材料：[Amplitude Product Analytics](https://www.amplitude.com/guides/product-analytics)。
