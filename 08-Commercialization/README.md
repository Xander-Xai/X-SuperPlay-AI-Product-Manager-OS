# 08 AI 产品商业化与单位经济

## 必修
- User / Buyer / Approver：谁使用、谁被绩效影响、谁决定预算、谁签约。
- 替代选择：人工服务、现有软件、外包、自建、拒绝购买。
- 收费方式：按席位、任务/用量、项目交付/服务、混合收费；选择与价值单位匹配的形式。
- SaaS B2B 与 B2C：获客路径、采购周期、切换成本、数据政策、服务成本与取消/退款。
- CAC/LTV 与留存口径；没有真实合同/收入时标 HYPOTHESIS，不算 ARR/PMF。

## 最小测算
可变成本/成功任务 = 推理与检索 + 重试 + 人工复核 + 变动基础设施 + 支持；贡献毛利 = 实际净收入 - 直接变动成本。研发/维护固定成本单独核算，不能把贡献毛利当净利润。

## 实战
用 [MVP/单位经济表](../templates/MVP-and-Unit-Economics.md) 测乐观/中性/悲观三档。先做人工/小样本可逆试点；无买方访谈、授权使用和支付回执则**不宣称商业成功**。客户订单和收入事实只能通过 OPC 权威仓确认。
