# AI 产品经理与产品工程师：作品集和面试

## 作品集
- **PM**：用户问题与证据、替代与决策、PRD/线框、AI 选型、评测与风险、数据指标、定价假设、决策复盘。
- **PE**：目标与边界、UI/API/DB/AI 纵切、固定 commit 与运行步骤、质量与成本对照、负例、安全、回滚和本人独立修错。

## 六大面试题
1. 客户要求多 Agent，但人工/规则方案也可行，你如何判断做不做？
2. 为什么 RAG 召回率高不能代表答案可信？如何设计拒答与证据评价？
3. 用户说“喜欢”，但没有行为/付款，下一步如何验证？
4. DAU 增加但任务成功率、留存与毛利下降，产品是否增长？
5. 工程师发现高风险越权问题，业务催上线，你如何协调取舍？
6. 用户操作可能双写，如何同时设计用户提示、工具审批和工程幂等？

**回答框架**：场景/限制 → 来源/权限 → 原替代 → 假设 → 指标/分母 → 最小试验 → 决策/反证 → 风险/回退 → 证据与复盘。真实经历/合成演练必须明确区分；私密职位和简历只在 Career OS 保存。
